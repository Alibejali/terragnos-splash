Privacy Policy

Effective October 11, 2026

Who we are

Terragnos. Questions about this policy can go to ali@terragnos.com.

This website

terragnos.com gives basic information about Terragnos. If you write to us or use the notify form, we use the name, email, and message you send only to respond to you. We do not sell personal data.

Terragnos Workspace email assistant

Terragnos Workspace is a Google app. With the account owner's consent, an email assistant uses it to read messages, apply labels, and draft replies in the mailbox the owner authorized. The assistant never sends email without the owner's explicit approval.

Data from that mailbox is used only to provide this service to the account owner. It is not sold, not used for advertising, and not used to train generalized AI models. It is stored on systems Terragnos controls. Access is limited to operating the service.

Google API Services User Data Policy

Terragnos Workspace's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

The use of information received from Google Workspace scopes will adhere to the Google User Data Policy, including the Limited Use requirements.

Revoke access or request deletion

You can revoke Terragnos Workspace's access at any time at https://myaccount.google.com/permissions.

To request deletion of data we hold, email ali@terragnos.com.

Changes

If this policy changes, we will post the updated version on this page and change the effective date. If a change would use Google user data in a new way, we will tell the account owner and ask for consent before that new use.
